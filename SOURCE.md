# Data provenance

All bundled matches and rosters are independently generated with seed 20261028.
Twenty fictional teams have 18 invented players each. IDs, shirts, colours,
ratings and profiles are generated without reading a real roster or old match.
Birth dates, nationalities, external player IDs and source-site profiles are absent.
Simulation frequencies use explicit engineering defaults, not imported calibration.
Q2 models are fitted only on the new synthetic matches, with disjoint matchweek folds.
These scores are simulation estimates, not validated real-football probabilities.

Code derives from LiNTe912/NextPlay-AI and tigerguoyi/NextPlay-AI. This export
does not include their Git history, original datasets, old fitted models, downloaded
clips, private uploads, credentials or the optional YOLO research implementation.
Video review accepts manual evidence locally; rights and observation confirmation
are required. The built-in generated clip is a synthetic workflow demonstration.

An optional StatsBomb-format aggregate research tool is included, but no external
calibration data or derived profile is activated or redistributed. See
[calibration status and rights review](docs/statsbomb-calibration.md).

Selected lightweight System 1 code from tigerguoyi/Microsoft_Hackthon is now
included in inside_the_game/, with the base commit, original source hashes and
compatibility changes recorded in inside_the_game/UPSTREAM.json. No upstream
fitted weights are included. The hand-set baseline does not change Q2 ranks.
No SPDX license is inferred from a public repository; applicable team permissions
and upstream obligations still apply.
